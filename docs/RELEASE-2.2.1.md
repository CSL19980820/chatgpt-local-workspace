# Local Workspace 2.2.1

任务提醒从时间线上方的大块常驻卡片改为计划标题旁的“任务详情”按钮。默认仅占用一行标题，不再挤压调用时间线。

- 点击按钮才打开详情；关闭后，轮询和状态变化不会自动重新打开。多个计划共用一个入口。
- 阻塞原因、执行记录与复制操作保留在详情里。历史执行问题默认折叠。
- 所有步骤已完成但缺少逐项证据时，说明“证据未逐项登记，不代表实际工作没有完成”，复制操作改为“复制核对提示”。不会自动把计划总说明视为逐项证据。
- 可以直接在原对话发送“继续”，不必使用复制按钮；不新增自动发送或唤醒行为。
- 完成检查及任务状态契约保持不变，工具数仍为 26。

使用真实 EXE 与浏览器验证默认收起、标题行高度、打开/关闭、状态更新不自动弹出、历史记录折叠、复制、完成状态以及窄窗口和深色样式。原有协议、命令、文件和完成检查回归继续覆盖。

程序构建在 `dist`，发行包继续包含 OpenAI Tunnel Client v0.0.14。现有 2.2.0 实例使用同目录 `dashboard.html`，替换页面后通过“更多 → 刷新工作台”即可加载新界面，无需为了界面刷新停止任务；完整程序版本在退出旧程序后启动新版时生效。
